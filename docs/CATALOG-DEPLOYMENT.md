## Расположение

На сервере общая база и выгрузка: `/opt/splithub_api_telegram/output/catalog.sqlite3`
и `/opt/splithub_api_telegram/output/catalog.json`. Ключи только в прежних `.env`.
Они и реальные выгрузки не публикуются в GitHub.

HTTP API для агентов пока не запущен: отдельный `TENDER_CLIMATE_API_TOKEN`
не настроен. Контент-агенты на сервере могут читать общий JSON/SQLite.
